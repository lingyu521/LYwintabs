# LYwintabs

LYwintabs 集成在 Windows 自带的文件资源管理器中。通过任务栏、`Win+E` 或双击文件夹打开资源管理器，就能在使用系统地址栏、搜索和文件操作的同一个窗口里，用标签切换目录、在横向收藏栏打开常用路径，或启动局域网互传。

| 系统 | 标签页与收藏栏 |
| --- | --- |
| Windows 10 22H2 x64 | 在资源管理器窗口顶部增加标签栏，在系统地址栏下方增加横向收藏栏。 |
| Windows 11 x64 | 使用资源管理器的系统原生标签页，在窗口中增加横向收藏栏。 |

## 功能介绍

### 标签页

在同一个资源管理器窗口中可以同时打开多个目录。例如，把「下载」和「文档」放在两个标签页里，点击标签就能切回对应的目录，继续使用系统地址栏、搜索或文件列表。

Windows 10 的标签栏提供以下操作。

- 点击 `+` 打开「此电脑」，再进入要浏览的目录。右键选择「复制标签」可在相邻位置打开同一目录。
- 点击标签切换目录，点击标签上的关闭按钮或右键选择「关闭标签」。关闭当前标签后会切换到相邻标签，关闭最后一个标签会关闭窗口。
- 左右拖动标签可以调整顺序。标签宽度按目录名称和可用空间调整，放不下的标签可从标签栏的下拉列表切换。窗口顶部空间不足时，标签栏会移到地址栏下方。

Windows 11 的新建、切换和关闭标签页使用系统原生控件。横向收藏栏可以与原生标签页一起使用。

### 收藏夹与书签管理

横向收藏栏用于保存常用目录。书签文件夹可以把相关路径集中放在同一组里，点击文件夹可展开并选择其中的书签。

- 要**收藏当前目录**，右键点击收藏栏空白处，选择「添加当前地址到书签…」。地址栏旁显示星标时，也可点击星标添加。保存时可选收藏栏根目录或已有的书签文件夹。
- **单击书签**可在当前标签中跳转。右键选择「编辑…」可修改名称或目标路径。Windows 10 还可选择「在后台标签打开」，继续浏览当前标签里的目录。
- **拖动书签**到相邻项的边缘可调整顺序，拖到书签文件夹中间可移入该文件夹。可从收藏栏空白处的右键菜单进入「书签管理器」，创建多层书签文件夹，或移动、编辑、移除收藏项。

可以在插件设置里显示或隐藏收藏栏，也可切换紧凑和加高两种高度。

### 局域网互传

点击收藏栏左侧的互传图标，或双击 Windows 通知区域的 LYwintabs 图标，即可打开互传面板。打开已启用 LYwintabs 的资源管理器窗口或切换目录时，插件会检查并按需启动后台互传。后台互传开启时，关闭面板也能收到文件请求弹窗。

1. **在「发送」页查找设备。** 附近设备按名称排列，每台设备占一行，支持按名称或 IP 搜索。也可以直接输入对方的局域网 IP 或 `IP:端口`。
2. **发起传输**时，添加要发送的文件或文件夹，也可从资源管理器拖入发送清单。选中目标设备并发送后，等待对方确认。
3. **接收文件**时，弹窗显示发送者、文件数量、大小和保存位置。可选择接收、另存为或拒绝。默认保存到当前用户的桌面，每批文件放进单独的子文件夹。「另存为…」只调整本批文件的保存位置。
4. **管理接收进度**时，可暂停、继续或终止。终止后会清理未传完的临时文件。

可以在互传设置中修改设备昵称和默认接收位置。未填写昵称时优先显示域账户的显示名称，缺失时使用计算机名。

设备发现与文件传输参考 **LocalSend v2** 公开协议，互传核心沿用同作者 LYIsland 的 C# 实现。[LocalSend 官方项目](https://github.com/localsend/localsend) · [LocalSend 协议规范](https://github.com/localsend/protocol) · [LYwintabs 互传使用说明](transfer/README.md)

## 兼容性

目标平台为 Windows 10 22H2 x64 和 Windows 11 x64。当前安装包的 EULA 页面、安装及卸载已在 Windows 10 22H2（19045.6456）实测。preview.27 的原生文件夹导航和互传自动启动已在 Windows 10 22H2 和 Windows 11 25H2 验证。

## 从源码构建

在 Visual Studio 2026 中打开 `LYwintabs.sln`，选择 `Release | x64` 生成 Explorer 插件和启动器。原生项目使用 C++20、MSVC v145 和 Windows SDK 10.0.26100.0。输出在 `out/explorer/x64/Release/`。

互传模块使用 .NET 10 和 C# WinForms。发布方式见[互传构建说明](transfer/README.md)。安装包使用 Inno Setup 7，脚本为 [Install-LYwintabs.iss](explorer/Install-LYwintabs.iss)，编译时传入插件 DLL、启动器 EXE、自包含互传目录及构建标识。
